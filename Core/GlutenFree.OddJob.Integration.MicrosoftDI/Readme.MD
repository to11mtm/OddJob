# GlutenFree.OddJob.Integration.MicrosoftDI

UwU! This project provides a super cute integration for Microsoft.Extensions.DependencyInjection with OddJob! 

Use `MicrosoftDiContainerFactory` to resolve your jobs and dependencies with the built-in DI system, nya~

## Usage

1. Register your services in an `IServiceCollection`.
2. Build your `IServiceProvider`.
3. Pass it to `MicrosoftDiContainerFactory`.
